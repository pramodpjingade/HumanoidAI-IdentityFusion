# HumanoidAI Identity Fusion

An AI-powered identity recognition system for humanoid robots, combining facial recognition and voice recognition through multimodal identity fusion.

## Features

- Facial recognition using InsightFace.
- Voice recognition using SpeechBrain.
- Independent face and voice identification.
- Multimodal identity fusion.
- Identity mismatch detection.
- Test cases for identity fusion.
